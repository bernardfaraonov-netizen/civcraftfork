Пути в таблицах указаны относительно `civcraft/src/com/avrgaming/civcraft/`. Полный путь получается так: `civcraft/src/` + `com/avrgaming/civcraft/` + путь из таблицы. Если файл лежит вне этих пакетов, путь указан явно (например, `global/...` — это `civcraft/src/com/avrgaming/global/...`). Номера строк сверены с исходниками.

Каждая находка подтверждена чтением кода. Предположения помечены словами «потенциально» или «если».

## Механики

### 0. Общая архитектура и хранение
- **БД**: MySQL через BoneCP. Три пула: *game* (таблицы с префиксом `mysql.table_prefix`), *global* (`GLOBAL_SESSIONS`, репорты, очки), *perk* (опционально, legacy Platinum).
- **Сохранение**: `SQLObject.save()` ставит объект в очередь `SQLUpdate`, фоновый поток вызывает `saveNow()` → `SQL.updateNamedObject`: при `id==0` делается `INSERT` (id берётся из auto_increment), иначе `UPDATE … WHERE id=?`. Схема создаётся и дополняется колонками в `init()` каждой сущности.
- **Порядок загрузки** (`CivGlobal.loadGlobals`): Camps → Civs → Relations → Towns (+WarRegen restore) → Residents → PermissionGroups → TownChunks → Structures → Wonders → WallBlocks → RoadBlocks → TradeGoods → RandomEvents → ProtectedBlocks → ArenaTeams → EventTimers → EndGame → War → Templates, затем `processUpgrades` (повторное применение апгрейдов города), `processCulture` (async-пересчёт культуры), `onLoadTask`. Цивилизации без столицы попадают в `orphanCivs`, города без цивилизации в `orphanTowns`.
- **Реестры в памяти** (`CivGlobal`): residents (по имени в нижнем регистре и по UUID), towns, civs, conqueredCivs, adminCivs, townChunks/cultureChunks (по `ChunkCoord`), structures/wonders (по угловому `BlockCoord`), structureBlocks, structureSigns/Chests, tradeGoods, protectedBlocks, farmChunks, bonusGoodies, wallChunks, roadBlocks, camps, markets, protectedItemFrames, questions (приглашения, запросы к лидерам, дипломатические запросы; не больше одного активного вопроса на адресата).
- **SessionDB** (таблица `SESSIONS`: `request_id, key, value, civ_id, town_id, struct_id, time`): универсальное key/value-хранилище с кэшем. Используется для кулдауна вступления (`cooldown:<name>` = id старой цивилизации), отложенной смены правительства (`changegov_<civId>` = id нового правительства), победы (`endgame:winningCiv`) и прочего. Глобальный вариант живёт в global DB.
- **Каналы сообщений** (`CivMessage`): Global, Town (флаг `showTown`), Civ (`showCiv`), Scout (`showScout`), чаты TC/CC с дополнительными слушателями (админы), Camp, Arena/Team. Ошибки, отправленные через `sendErrorNoRepeat`, не повторяются подряд.

### 1. Resident (житель), таблица `RESIDENTS`
- **Поля в БД**: `id`, `name` (UNIQUE, фактически первичный идентификатор), `uuid`, `town_id`, `camp_id`, `lastOnline`, `registered`, `friends` (имена через запятую), `debt`, `coins`, `daysTilEvict`, `givenKit`, `timezone`, `banned`, `flags` (`map, showtown, showciv, showscout, info, combatinfo, itemModeRare/None`), `last_ip`, `savedInventory` (сериализованный инвентарь перед ареной), `insideArena`, `isProtected`, `debug_town/civ`.
- **Состояние только в памяти**: режимы чата (town/civ/admin, override-город и override-цивилизация, allchat), `permOverride`/`sbperm` (админский обход), `spyExposure` (0..1000, отображается в XP-баре), перки, интерактивный режим ответа в чате, превью постройки, `selectedTown`, `pendingBuildable`, `onRoad` (под ногами блок дороги), scoreboard, `desiredCivName/TownName/Template` при основании.
- **Стартовые деньги**: `global.starting_coins = 250`.
- **Налоги** (раз в сутки в `daily_upkeep_hour = 20`): имущественный налог = Σ по участкам, которыми житель владеет, `plot.value × town.taxRate`; подушный налог = `town.flatTax`. **Мэры и ассистенты освобождены.** Если денег не хватает, житель платит сколько есть, остаток уходит в долг; при переходе в долг `daysTilEvict = GRACE_DAYS = 3`. Каждые сутки счётчик уменьшается (если >0), на 0 житель выселяется: участки возвращаются городу (перм-группы сбрасываются на residents), долг обнуляется, ставится кулдаун вступления. `/resident paydebt` переводит весь долг казне города.
- **Кулдаун вступления**: `global.join_civ_cooldown = 24` ч, отсчитывается от ухода из цивилизации. Вступать в город своей же цивилизации можно без ограничений.
- **Друзья**: друг владельца участка получает права «владельца» (см. PlotPermissions).
- **Технологии для предметов**: кастомный предмет с `required_tech` (список через запятую) используется, только если цивилизация изучила все эти технологии; на арене ограничение не действует.
- **Магазины** (`buyItem`): списывается цена, выдаются предметы; нерезидент платит сверху налог нерезидента.
- **Обмен (trade GUI)**: 5 рядов. Верхний ряд — другой игрок (подтверждение, «Coins Offered»), нижний — свой (−100/−1000, +100/+1000 монет, подтверждение), в середине разделитель.
- **Смерть и дом**: `teleportHome` переносит в случайную точку возрождения ратуши своего города, без города — на спавн мира `world`.
- **Контрольные блоки**: ломать можно, только если Capitol своей цивилизации валиден.
- **Неактивность**: `isInactiveForDays(n)` по `lastOnline`. Мэры неактивны после `town.mayor_inactive_days = 7`, лидеры после `civ.leader_inactive_days = 7` (такой город или цивилизацию можно «перезахватить»).
- **Перки**: бесплатные перки выдаются по `perks.system.free_perk_count` (100). Шаблоны перков: персональные (`CustomPersonalTemplate`) и городские (`CustomTemplate`).

### 2. EconObject (кошелёк)
- Поля: `coins`, `debt`, `principalAmount` (база для процентов банка). Все значения **округляются вниз до целого**, отрицательные суммы превращаются в 0. `setBalance(<0)` даёт 0.
- `withdraw` дополнительно уменьшает `principal`, если баланс опускается ниже него (проценты банка начисляются только на «неснятую» часть).
- `payTo(to, x)`: проверяет, что денег хватает, затем списывает и зачисляет. `payToCreditor(to, x)`: платит сколько есть, остаток уходит в `debt`.
- Долг не влияет на баланс. Погашение идёт через `depositFromResident` (Town/Civ): сначала гасится долг, остаток зачисляется в казну. Когда долг погашен, `daysInDebt = 0`.

### 3. Town (город), таблица `TOWNS`
- **Поля в БД**: `name` (UNIQUE), `civ_id`, `mother_civ_id` (исходная цивилизация захваченного города), `level` (1..9), `coins`, `debt`, `daysInDebt`, `flat_tax`, `tax_rate`, `extra_hammers`, `culture` (int), `upgrades` (id через запятую), `outlaws` (имена), `created_date`; имена групп захардкожены (`residents`, `mayors`, `assistants`).
- **Состояние только в памяти**: residents, townChunks, outposts, cultureChunks, structures, wonders, disabledBuildables, bonusGoodies (товары в рамках ратуши), BuffManager, очередь стройки `build_tasks`, текущая стройка и текущее чудо (**одновременно одна структура и одно чудо**), invalidStructures, baseHappy/baseUnhappy (задаются событиями и апгрейдами), activeEvent, unusedBeakers, флаги pvp/defeated/claimed, кэш атрибутов (5 с).
- **Основание города** (`newTown`):
  - нельзя в военное время, если цивилизация воюет (кроме бесплатного основания);
  - нельзя, будучи мэром другого города или состоя в лагере;
  - имя города должно быть уникальным, чанк свободен, культура чужой цивилизации в точке основания запрещена;
  - расстояние между ратушами не меньше `town.min_town_distance = 150` блоков (`300`, если с владельцем той ратуши идёт война);
  - в радиусе `civ.min_distance = 15` чанков нет чанков чужих городов;
  - игрок должен быть юнитом **Settler** (`u_settler`), кроме бесплатного основания (столица при создании цивилизации);
  - создаются группы residents (основатель), mayors (основатель) и assistants, заклеймляется стартовый чанк, в казну кладётся стоимость `s_townhall`/`s_capitol`, и эта структура тут же строится (фактически бесплатно). Предмет-поселенец потребляется, основатель уходит из прежнего города.
- **Уровни** (`town.yml`), в столбцах апкип / максимум участков / цена участка / тайл-улучшения:
  1 Settlement 500/32/500/4; 2 Hamlet 750/64/1000/6; 3 Village 1250/80/2000/8; 4 Large Village 2000/128/3500/12; 5 Town 3500/256/5000/15; 6 Large Town 5500/512/7500/17; 7 City 7000/1024/15000/20; 8 Large City 8000/2048/20000/25; 9 Metropolis 25000/4096/30000/30.
  Повышение уровня — это апгрейды `upgrade_town_level_N` (стоимость 10k, 20k, 30k, 50k, 125k, 250k, 500k…), каждый требует предыдущий апгрейд и технологию (code_of_laws, priesthood, monarchy, currency, alchemy, construction, innovation…).
- **Апгрейды** (`purchaseUpgrade`): нужны требуемый апгрейд, деньги в казне и активная требуемая структура. Затем выполняется `processAction` (например, `set_town_level,N`); если он падает, деньги возвращаются. При загрузке все апгрейды применяются повторно.
- **Лимиты построек**: `limit` на тип структуры; тайл-улучшения ограничены полем `tile_improvements` уровня города. Лишние структуры отключаются (`disabledBuildables`).
- **Стройка**: проверяются апгрейд, технология, доступность, место (`canBuildHere`, `MIN_DISTANCE`), лимит, деньги, `runCheck`. Стоимость списывается после успешного старта. Чудо должно быть глобально уникальным (в casual-режиме уникально в пределах цивилизации) и строится только в мире `world`. «Лишние» молоты (`extraHammers`) делятся поровну между активными задачами стройки; если ничего не строится, они копятся.
- **Производство** (все значения кэшируются на 5 с):
  - **Молоты** = max(base, (CONSTRUCTION-баф (int, 100 у `buff_construction`) + Σ молотов культурных чанков + Σ атрибутов HAMMERS структур + `base_hammer_rate` 1.0) × rate). rate = happiness.hammer_rate × gov.hammer_rate × randomEvent × (`war.captured_penalty = 0.75`, если город захвачен).
  - **Культура/ч** = (EXTRA_CULTURE-баф [мёртвый] + Σ атрибутов CULTURE структур) × rate. rate = gov.culture_rate × happiness.culture_rate + fine_art-баф + pyramid-баф. Начисляется в `addAccumulatedCulture`; при достижении порога следующего уровня запускается пересчёт культуры и выводится сообщение «borders expanded».
  - **Рост** = (Σ роста культурных чанков + Σ атрибутов GROWTH + `base_growth_rate` 1.0) × (gov.growth_rate + year_of_plenty + hanging_gardens_growth + hanging_gardens_additional × число товаров «grapes»).
  - **Колбы** = (Σ колб культурных чанков + Σ атрибутов BEAKERS) × happiness.beaker × gov.beaker × (1 + innovation + greatlibrary_extra_beakers).
  - **Коттеджи**: rate = gov.cottage_rate × (1 + cottage-баф [мёртвый]) × happiness.coin_rate.
  - **Торговля**: rate = (gov.trade_rate + Σ атрибутов TRADE-rate структур) × (1 + monopoly) × happiness.coin_rate. Выплата = Σ по товарам в рамках ратуши, у которых аванпост активен и стоит в культуре: `good.value × (1 + 0.5 × min(n_одинаковых − 1, trade_good_multiplier_max = 3))`, затем × trade rate.
- **Счастье**:
  - H = счастье уровня города (12 на всех уровнях) + `buff_hedonism` (3.0, стекается) + число товаров в рамках + baseHappy + Σ счастья культурных чанков + Σ положительных атрибутов HAPPINESS структур (не меньше 0) + случайные события.
  - U = по цивилизации: 1.0 за каждый нестоличный собственный город, 2.0 за каждый захваченный, за каждую войну, где цивилизация агрессор: `per_war 3.0 + min(scoreDiff × 0.0001, 5.0)`; плюс 1.0 × число жителей; плюс удалённость от столицы (не для столицы и не для захваченного города): `0.01 × dist^0.75`, если культура города связана со столичной через цепочку своих городов (`touchesCapitolCulture`), иначе `0.01 × dist^1.05`, максимум 15, округление; плюс baseUnhappy, Σ отрицательных HAPPINESS структур, случайные события.
  - Доля счастья = H/(H+U), по ней выбирается состояние (порог, затем множитель колб, монет, культуры и молотов): Revolt (0) 0.2; Unrest (0.2) 0.5; Unhappy (0.4) 0.75; Content (0.5) 1.0; Happy (0.7) 1.15; Elated (0.85) 1.3; Ecstatic (0.92) (значение в конфиге).
- **Правительство города**: совпадает с правительством цивилизации. Исключение: цивилизация в анархии, а город захвачен — тогда действует правительство материнской цивилизации (если она не в анархии) или tribalism.
- **Доход с налогом** (`depositTaxed`): `income × civ.income_tax_rate` уходит цивилизации (`taxPayment`). Если город захвачен, остаток умножается на `captured_penalty 0.75`, и 25% исчезают.
- **Ежесуточный апкип** (`payUpkeep`):
  - апкип = (апкип уровня + Σ `upkeep` структур + апкип аванпостов (сейчас 0)) × gov.upkeep_rate;
  - Колосс: ×(1 − 0.25) для владельца; у «пиявимых» городов 2% суммы начисляется городу Колосса;
  - если денег не хватает: столица перекладывает нехватку на казну цивилизации (или в её долг), обычный город уходит в свой долг;
  - «spread upkeep» (10 × (dist_чанка − 8)^1.5 за каждый чанк дальше 8 чанков от ратуши) рассчитывается и показывается, но **не списывается**.
- **Долг города**: `daysInDebt++` ежесуточно; при ≥ `TOWN_DEBT_GRACE_DAYS = 7` город выставлен на продажу, при ≥ `TOWN_DEBT_SELL_DAYS = 14` город распускается («fell into ruin»). Город также продаётся, если продаются все города его цивилизации.
- **Очки**: Σ очков структур и чудес + 5000 × жители + 200 × городские чанки + 100 × культурные чанки + `казна / coins_per_point (5)`. Цена продажи города = очки × 5.
- **Изгнанники** (outlaws): список имён; изгнанники подсвечиваются красным и считаются враждебными на территории города (`isOutlawHere`, `isMutualOutlaw`). При смене цивилизации из списка удаляются жители новой цивилизации.
- **Поражение и освобождение** (`onDefeat`): при первом захвате `motherCiv` = прежняя цивилизация; если город отвоевала `motherCiv`, поле сбрасывается. `capitulate` снимает `motherCiv`; если город — столица материнской цивилизации, капитулирует вся цивилизация.
- **Шпионаж**: доля экспозиции шпиона = exposure/1000. Пороги: warning 0.4 («нас шпионят»), location 0.8 (координаты шпиона), name 0.9 (имя), failure 1.95 (миссия сорвана).
- **Прочее**: `refresh` ближайшей постройки (только мэр, кулдаун `buildable_refresh_cooldown = 30` мин, не во время войны); подарок или слияние возможны с возраста `civ.min_gift_age = 14` дней, стоимость `gift_cost_per_town = 150000`; переименование; `processStructureFlipping` — структура в культуре чужой цивилизации переходит к городу, владеющему этой культурой.

### 4. Civilization (цивилизация), таблица `CIVILIZATIONS`
- **Поля**: `name` (UNIQUE), `leaderName`, `capitolName`, `coins`, `debt`, `daysInDebt`, `techs`/`researched` (id через запятую), `researchTech`, `researchProgress`, `government_id`, `color` (24-бит RGB), `income_tax_rate`, `science_percentage`, группы `leaders` и `advisers`, `lastUpkeepTick`/`lastTaxesTick` (`key:value;` для UI), `adminCiv`, `conquered`, `conquered_date`, `created_date`. В памяти: towns, DiplomacyManager, warCamps.
- **Основание**: в руке предмет с компонентом `FoundCivilization` (он потребляется); уникальные имена цивилизации и столицы; игрок не в лагере; ≥ `civ.min_distance = 15` чанков до любого культурного чанка. Создаются группы leaders (основатель) и advisers, столица основывается бесплатно, правительство — Tribalism, цвет случайный.
- **Правительства** (`governments.yml`), в столбцах trade/cottage/upkeep/growth/max_tax/culture/hammer/beaker:
  - Anarchy 0/0/5.0/0.3/0/0/0.5/0.5;
  - Tribalism 0.8/0.8/1.0/0.5/0.05/1.0/1.0/1.0;
  - Despotism (tech_productivity) 0.8/0.8/1.25/0.5/0.10/1.0/1.10/1.0;
  - Monarchy (tech_monarchy) 0.8/1.5/1.5/0.8/0.30/1.05/1.0/1.0;
  - Theocracy (tech_global_trade) 2.0/0.8/1.15/0.75/0.5/1.25/1.0/1.0;
  - Communism (tech_construction) 1.0/1.0/0.75/0.85/0.20/1.0/1.75/1.0;
  - Republic (tech_republic) 0.8/0.8/1.5/0.8/0.40/1.0/1.0/1.0.
  
  Смена правительства переводит цивилизацию в Anarchy на `anarchy_duration = 24` ч (запись `changegov_<id>` в SessionDB, завершает `ChangeGovernmentTimer`). Баф `buff_noanarchy` (Нотр-Дам) позволяет сменить правительство сразу. Из анархии сменить правительство нельзя.
- **Налог и наука** (`taxPayment`): из налоговой суммы доля `science_percentage` конвертируется в колбы по курсу `coins_per_beaker = 10` (курс ÷2 за каждый город с `buff_greatlibrary_double_tax_beakers`), остаток идёт в казну. Если ничего не исследуется и активна научная победа, колбы идут в «Enlightenment».
- **Исследование**: старт стоит `tech.cost` монет и требует пререквизитов. Прирост раз в минуту (BeakerTimer) = (Σ колб городов + `base_beaker_rate` 1.0) / 60. При `progress ≥ beaker_cost` технология изучена, прогресс обнуляется (**избыток теряется**), всем структурам вызывается `onTechUpdate`. В чат цивилизации сообщается каждые 10%. Без активного исследования колбы копятся в `town.unusedBeakers` или идут на научную победу.
- **Ежесуточный апкип цивилизации**: `civ.town_upkeep = 500` за каждый нестоличный город + военный апкип. Военный апкип начисляется за каждую войну, где цивилизация агрессор: `war.upkeep_per_war 3000 + max(0, scoreDiff) × 0.005`, ×2, если у противника или его союзников есть `buff_notre_dame_extra_war_penalty`. Дистанционный апкип городов (`100 × dist^0.3` при связанной культуре, `^0.9` при несвязанной, максимум 500000) **только отображается**. Если денег не хватает, недостача уходит в долг.
- **Долг цивилизации**: `daysInDebt++`; ≥ `CIV_DEBT_GRACE_DAYS = 7` — цивилизация продаётся (и не может вести агрессивных войн: они снимаются в DailyTimer); ≥ `CIV_DEBT_SELL_DAYS = 14` — продаются её города; ≥ `CIV_DEBT_TOWN_SELL_DAYS = 21` — цивилизация удаляется целиком.
- **Рынок**: цена цивилизации = техно-очки × 5 + Σ цен городов. `buyCiv` сливает цивилизацию в покупателя (`mergeInCiv`: все города переходят, их долги прощаются, старая цивилизация удаляется). `buyTown` возможен только для не-столицы, не в военное время и не в течение 3 дней до войны. Деньги сгорают.
- **Очки**: Σ очков городов + Σ `points` технологий. Пересчёт раз в минуту (async), запись в глобальную таблицу очков.
- **Поражение** (`onDefeat`): все города отходят атакующему (`Town.onDefeat`), все отношения удаляются, цивилизация помечается `conquered` и переносится в список покорённых. Революция стоит `revolution.base_cost 50000 + 20000 × города с motherCiv=этой + (техно-очки + очки таких городов) × 0.1`, максимум 5·10⁷; кулдаун `civ.revolution_cooldown = 7` дней. `capitulate` снимает `motherCiv` у всех её бывших городов и удаляет цивилизацию.
- **Завоевательная победа**: `getPercentageConquered` = (1 + число покорённых цивилизаций, чью столицу держит эта) / (активные + покорённые цивилизации).
- **Возрождение** во время войны: ратуши городов (кроме побеждённых нестоличных) и военные лагеря. `repositionPlayers` переносит жителей из вражеской культуры к ратуше.

### 5. Relation / DiplomacyManager
- Статусы: NEUTRAL, HOSTILE, WAR, PEACE, ALLY (MASTER/VASSAL закомментированы). Хранятся **две записи на пару** (по одной с каждой стороны), поля `civ_id, other_civ_id, relation, aggressor_civ_id, created, expires`.
- Отношение к самой себе — ALLY, отсутствие записи — NEUTRAL. `isHostileWith` = WAR или HOSTILE. `warCount` служит для быстрой проверки `isAtWar()`.
- `CivGlobal.setRelation` ставит статус обеим сторонам и объявляет об этом в глобальный чат. Агрессор назначается обеим сторонам через `setAggressor`.
- Цвет тега игрока над головой: своя цивилизация и союзник — LightGreen, PEACE — LightBlue, HOSTILE — Yellow, WAR — Rose, изгнанник — Red.
- Дипломатические запросы идут через `CivQuestionTask`: не больше одного активного на цивилизацию, тайм-аут около 30 с.

### 6. TownChunk (участок), таблица `TOWNCHUNKS`
- Поля: `town_id`, `world`, `x`, `z`, `owner_id`, `groups` (id групп), `permissions` (строка PlotPermissions), `for_sale`, `value` (цена последней покупки, база налога), `price` (цена продажи), `outpost`.
- **Клейм** (`claim`): чанк свободен; в казне хватает на цену следующего участка (цена = `plot_cost` минимального уровня, у которого `plots` > текущего числа участков: <32 → 500, <64 → 1000, <80 → 2000, <128 → 3500 и т.д.); чанк лежит в культуре своей цивилизации; для обычного участка — соседство по стороне с неаванпостным участком своего города и `участков < plots` уровня; в радиусе 15 чанков нет чанков чужих цивилизаций. Лагерь в чанке распускается, запускается пересчёт культуры. **Аванпосты** не требуют смежности и не считаются в лимит.
- Ратуша клеймит свои чанки бесплатно (`townHallClaim`).
- **Покупка участка жителем**: цена уходит владельцу (или городу, если владельца нет), `value = price`, участок снимается с продажи, группы очищаются.
- `isEdgeBlock`: граничит с пустотой или аванпостом.

### 7. Права (permission/)
- **PlotPermissions**: 4 узла (build, destroy, interact, itemUse), в каждом флаги `permitOwner/permitGroup/permitOthers` (по умолчанию true/true/false); флаги `fire`, `mobs`; владелец (Resident); список групп.
- Проверка права: `permOverride` → владелец → **друг владельца** (с правами владельца) → член любой группы участка → «прочие».
- Новый участок получает группу `residents` своего города, поэтому по умолчанию все жители строят везде. `resetPerms` при выселении владельца возвращает значения по умолчанию.
- **PermissionGroup** (таблица `GROUPS`: `name, town_id, civ_id, members`): защищённые городские группы `mayors`, `assistants`, `residents`; группы цивилизации `leaders`, `advisers`; плюс пользовательские группы города. Члены хранятся по имени (или по UUID при `useUUID=true`, сейчас выключено).
- Выбрать город через `/town select` может член mayors, assistants или residents этого города, а также лидер или советник его цивилизации.

### 8. CultureChunk (культура)
- Культурная территория создаётся от ратуши асинхронным пересчётом. Радиус в чанках задан таблицей `culture_levels`: 0/6, 500/8, 10000/10, 20000/13, 100000/15, 250000/17, 500000/19, 1M/22, 2M/26, 4M/32, 5M/40 (с учётом смещения уровня, см. H9).
- **Сила** чанка при споре = `amount(уровня) / distance²` (в собственной точке бесконечна).
- **Доход чанка**: берётся из `culture_biomes` по биому (coins/hammers/growth/happiness/beakers; например, PLAINS: 0/0.25/2.0/0.025/0.5, OCEAN: 0/0.5/0.25/0.02/1.0; неизвестный биом даёт нули) плюс атрибуты `AttributeBiome*` структур в радиусе. Биом кэшируется в таблице `CHUNK_BIOMES`.
- Вход и выход из границ сопровождаются сообщениями «Entering/Leaving <Civ> Borders». `/here` показывает доход биома.

### 9. Бафы (Buff/BuffManager, `buffs.yml`)
- Баф: `id`, `name`, `value` (строка), `stackable`, `parent` (по умолчанию равен id; уровни бафа наследуют родителя).
- Менеджер хранит все бафы по ключу источника (`tradegood:<outpost>:<buffId>`, чудо и т.п.) и «эффективный» набор: стекающиеся бафы все, нестекающиеся — только первый с данным id. Сумма считается по `parent`.
- Ключевые значения: construction +100 молотов (int), year_of_plenty +0.2 роста, innovation +0.1 науки, monopoly +0.3 торговли, preservative 0.5, fine_art +0.25 культуры (нестек.), hedonism +3 счастья (стек.), rush 0.15, barter 0.05, greed 0.03, medicine 50, fishing 2; пирамида: cottage ×1.1, culture «1.1», cottage consume 0.25, leech 1%; Великая библиотека: +10% колб, курс колб из налогов ×2; Висячие сады: growth +0.25, regen 0.5, +0.1 роста за каждый «grapes»; Колосс: −25% апкипа, лич 2% апкипа, монеты от культуры 5; Нотр-Дам: без анархии, 100 монет за мир, ×2 военный штраф врагам; Чичен-Ица: HP башен +15%, реген ×2, +10 HP контрольных точек.

### 10. TradeGood / товары
- Таблица `TRADE_GOODS` (`name`=id из goods.yml, `town_id`, `structure_id`, `coord`, `bonusLocation`). Товар генерируется популятором мира; на нём строится TradeOutpost, который производит BonusGoodie.
- BonusGoodie в рамке ратуши даёт городу бафы товара, +1 счастья и доход по торговой формуле (раздел 3). Дубликаты в рамках удаляются `checkForDuplicateGoodies`.

### 11. Прочие объекты
- **StructureBlock**: блок постройки. Ломается только в военное время, только цивилизацией, воюющей с владельцем, только если у структуры `maxHP > 0`, город атакующего не побеждён, блок `damageable` и не «мгновенно ломаемый» (стекло, факелы, растения и т.п. из `willInstantBreak`). У `alwaysDamage` все проверки кроме войны пропускаются.
- **ControlPoint**: контрольный блок ратуши с HP; уничтожен при HP ≤ 0.
- **WallBlock** (`WALLBLOCKS`): блок стены с исходным и новым типом (для отката).
- **ProtectedBlock** (`PROTECTED_BLOCKS`): типы TRADE_MARKER, PROTECTED_RAILWAY.
- **StructureSign/StructureChest**: интерактивные таблички (действие, текст, правый клик) и сундуки структур (`chestId` связывает двойные).
- **MissionLogger** (`MISSION_LOGS`): журнал шпионских миссий (город, цель, игрок, миссия, результат, время).
- **Кэши**: `PlayerLocationCache` — координаты, смерть и vanish онлайн-игроков для async-проверок близости (обновляется каждые 10 тиков). `ArrowFiredCache` — самонаводящиеся стрелы башен (живут 5 с, наведение каждые 5 тиков, прекращается ближе `homing_stop_distance`). `CannonExplosionProjectile` — ядро пушечной башни: скорость 6, урон 40, сплэш в квадрате расстояния < 30 (радиус около 5.5 блока), поджигает воздух в кубе 6×6×6 вокруг точки попадания и в 4 точках на расстоянии 3 блоков.
- **Утилиты**: `ChunkCoord`/`BlockCoord` — координаты с ключом «world,x,(y),z»; `MultiInventory` — объединение сундуков для выдачи и списания ресурсов (сравнение по custom id или по id+data, если у предмета нет прочности); `AsciiMap` — карта 9×40 чанков (T — участок: зелёный — со владельцем, красный — без; $ — продаётся; O — аванпост); `DateUtil`; `TimeTools` (секунды в тики ×20); `ItemFrameStorage` — рамки для товаров по UUID сущности.

### 12. Рекомендации к модели данных для переписки
- Идентичность: UUID игрока и числовые или UUID id сущностей. Имена хранить как атрибуты.
- Деньги: `long` в минимальных единицах, операции через `Ledger` с проверкой инварианта суммы.
- Отношения: одна запись на пару цивилизаций с явным агрессором и сроком действия.
- Вся игровая логика в главном потоке; async только для IO с неизменяемыми снимками.
- Все формулы раздела «Механики» покрыть unit-тестами на значениях из конфигов.
